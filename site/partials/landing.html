    The source, as plain data
    
      
    
    
    
  
    
  
    
    Tokens are plain, serializable data with no closures. A model can
    change darkest to mostVivid and explain the
    change, which is safer than inventing a new hex code. The package ships a
    skill file
    that teaches agents to move an existing system onto rules.
  
    

    



    
  
    
    
    What it is built on
    
  
    

  
    
    
    
      
    Your taste stays yours
    
      
    Rules select and mix the colors you give them; they never invent their own. Make the primitives however you like, with a generator, a brand book or your eye, and write a plain value wherever a rule is not what you mean.
    
    
    
    
    
      
    Rules, not values
    
      
    Selectors pick from a palette (darkest, closest, bestContrastWith). Transforms derive from a token (lighten, colorMix, ramp). A plain value is still allowed wherever it is the honest answer.
    
    
    
    
    
      
    Readable by construction
    
      
    Pass readableOn to any color selector and it only considers colors that meet WCAG contrast on that surface. When nothing passes, you get an error, not an unreadable color.
    
    
    
    
    
      
    A dependency graph
    
      
    Every reference is an edge. Changing a token re-resolves exactly what depends on it, and a write that would create a cycle is refused.
    
    
    
    
    
      
    Scopes inherit
    
      
    A button-danger scope extends button and overrides only its background. Relative references such as ref('.bg') resolve in the scope that inherits them.
    
    
    
    
    
      
    Variations are books
    
      
    Each theme, brand or breakpoint is a separate book built by the same function. Render one fully and the others as the differences from it.
    
    
    
    
    
      
    One source, many outputs
    
      
    CSS custom properties that keep var(), color-mix() and calc() live in the browser, resolved JSON, or W3C Design Tokens.
    
    
    
  
    

    



    
  
    
    
    Start with one rule.
    
  
    
  
    

    import {
  DesignBook, color, ref, darkest, bestContrastWith,
} from 'design-book';

const book = new DesignBook('site');
const ledger = book.addScope('ledger');
ledger.set('paper', color('#eee9dc'));
ledger.set('ink',   color('#22201c'));

const ui = book.addScope('ui');
ui.set('ground', darkest(ref('ledger')));
ui.set('ink',    bestContrastWith(ref('ui.ground'), ref('ledger')));

book.render('css-variables');
